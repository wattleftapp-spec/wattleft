Support

Wattleft shows the charge of your Marstek home battery and turns current consumption into hours and minutes left — in the app, in widgets and on the Lock Screen.

Need help? Write to wattleft.app@gmail.com — include your station model and iPhone/iOS version. We usually reply within a few days.

Getting started

  1. In the Marstek app, open your station's settings and turn on Open API (may be called Local API). Keep the default port 30000.
  2. Find the station's IP address in the Marstek app or in your router's device list.
  3. In Wattleft, enter the IP address and tap Check connection. Allow Local Network access when iOS asks.

Tip: reserve a fixed IP for the station in your router (DHCP reservation), so the address doesn't change after a router restart.

Common questions

Which stations are supported?

Marstek Venus E, C, A and D with Open API enabled. If your station doesn't show the Open API option, update its firmware in the Marstek app.

“The station did not respond”

  • Your iPhone must be on the same Wi‑Fi network as the station.
  • Check that Open API is on and the port matches.
  • Check Settings → Wattleft → Local Network is enabled.

The app says “charging” while the station is discharging

Some firmware reports power with the opposite sign. Turn on Invert grid power sign in Wattleft settings.

How often do widgets update?

iOS refreshes widgets about every 15 minutes; between updates the remaining charge is estimated from the current load. The Lock Screen Live Activity counts down every second.

Can I try it without a station?

Yes — tap See demo on the first screen, or turn on Demo mode in settings.

Підтримка

Wattleft показує заряд домашньої станції Marstek і переводить поточне споживання в години й хвилини — у застосунку, віджетах і на заблокованому екрані.

Потрібна допомога? Напишіть на wattleft.app@gmail.com — вкажіть модель станції та версію iPhone/iOS.

Як підключити

  1. У застосунку Marstek відкрийте налаштування станції та увімкніть Open API (може називатися Local API). Порт залиште 30000.
  2. Знайдіть IP-адресу станції в застосунку Marstek або в списку пристроїв роутера.
  3. У Wattleft вкажіть IP і натисніть «Перевірити зв’язок». Дозвольте доступ до локальної мережі, коли iOS запитає.

Порада: закріпіть IP за станцією в роутері (резервування DHCP).

Часті запитання

Станція не відповідає

  • iPhone і станція мають бути в одній Wi‑Fi мережі.
  • Open API увімкнено, порт збігається.
  • Параметри → Wattleft → «Локальна мережа» увімкнено.

Показує «Заряджання», хоча станція розряджається

Увімкніть у налаштуваннях «Інвертувати знак потужності мережі».

Можна спробувати без станції?

Так — «Переглянути демо» на першому екрані або «Демо-режим» у налаштуваннях.
