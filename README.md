# Wattleft — заряд станции Marstek на iPhone

Показывает заряд станции Marstek Venus и сколько времени он ещё продержится при текущем потреблении.

## Что внутри
- **Онбординг** при первом запуске: как включить Open API, найти IP станции и проверить связь (повторно — в Настройках → «Как подключить станцию»).
- **Приложение**: заряд, текущая нагрузка, оставшееся время, калькулятор «а если подключить N Вт».
- **Виджеты**: маленький и средний на домашний экран; круглый, прямоугольный и строчный на экран блокировки. На виджете есть кнопка ↻ для обновления.
- **Live Activity** (постоянный мониторинг): плашка на экране блокировки и в Dynamic Island. Оставшееся время и полоска заряда идут в реальном времени, их отсчитывает сама iOS. Данные со станции обновляются каждые 10 с, пока приложение открыто, при фоновых обновлениях iOS (обычно раз в 15–30 мин) и по кнопке ↻. Включается тумблером в приложении.
- Данные берутся по локальному API станции (UDP JSON-RPC, метод `ES.GetStatus`, порт 30000).

## Как считается время
- `энергия = SOC% × ёмкость` (ёмкость `bat_cap` из станции или задаётся вручную)
- `нагрузка = ongrid_power⁺ + offgrid_power⁺ − (заряд из сети + солнце)`, усреднённая за 10 минут
- `время = (энергия − резерв) / нагрузка`; при заряде показывается время до 100%

## Установка на iPhone
1. В приложении Marstek включите **Open API / Local API** и оставьте порт 30000. Закрепите IP станции в роутере.
2. Откройте `MarstekBattery.xcodeproj` в Xcode.
3. Для обоих таргетов (MarstekBattery и MarstekWidgetExtension) в Signing & Capabilities выберите свою команду (Team).
   При необходимости поменяйте bundle id `app.wattleft.ios` и App Group `group.app.wattleft.ios` на свои
   (App Group меняется в `App.entitlements`, `Widget.entitlements` и `Shared/BatteryModel.swift` → `SharedStore.groupID`).
4. Запустите на телефоне и пройдите онбординг: введите IP, разрешите доступ к локальной сети, «Проверить связь».
5. Добавьте виджет «Заряд станции» (приложение Wattleft) на домашний экран.

## Ограничения
- iOS обновляет виджет примерно раз в 15 минут. Между обновлениями таймер оставшегося времени идёт сам, а процент «отматывается» по текущей нагрузке; кнопка ↻ обновляет сразу.
- Таймер считает при той нагрузке, которая была при последнем замере. Если нагрузка резко изменится, время поправится при следующем обновлении.
- iOS снимает Live Activity примерно через 8 часов. Откройте приложение, и она запустится снова.
- На затемнённом экране блокировки iOS показывает секунды как «--», это нормально.
- Работает только в той же Wi-Fi сети, что и станция. Вне дома виджет показывает последние данные с пометкой «данные устарели».
- Если при разряде приложение пишет «заряжается», включите в настройках «Инвертировать знак мощности сети».
